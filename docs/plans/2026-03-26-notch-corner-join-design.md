# Notch Corner Join Design

**Date:** 2026-03-26

**Status:** Confirmed

## Summary

本次设计修复刘海折叠态右侧扩展块与系统刘海右下角之间的空隙：

1. 保留当前“刘海右侧小扩展块”作为折叠态入口，不改交互和展开时机。
2. 扩展块在左下角增加一段向刘海内侧延伸的拼接曲线，用来补上系统刘海右下圆角留下的缺口。
3. 扩展块整体仅在底部向左侵入刘海区域，顶部仍与当前右边界对齐，避免改坏现有宽度感知。

## Root Cause

当前折叠态存在两个几何问题：

1. 扩展块从 `notchFrame.maxX` 开始绘制，只贴住了刘海外接矩形的右边界。
2. 扩展块形状左侧是一条直线，没有补齐真实刘海右下角的圆角轮廓。

这会让系统壁纸或菜单栏背景从接缝下方露出来，形成截图中的缺口。

## Chosen Approach

采用“最小几何补偿”方案，只修改折叠态扩展块。

### Shape

- 为折叠态扩展块增加 `collapsedJoinRadius`。
- 形状左侧顶部仍保持直线对齐。
- 左下角新增一段向外凸出的拼接曲线，使扩展块底部轻微吃进刘海区域。

### Layout

- 扩展块可视宽度增加一个拼接补偿宽度。
- 扩展块整体向左回退同样的补偿距离。
- 这样顶部对齐关系不变，只有底部多出一块补偿面来填平缝隙。

### Scope

- 只改 `NotchCollapsedView` 和 `NotchPanelStyle`。
- 不修改 `NotchDisplayController` 的展开/收起行为。
- 不改变展开态 bridge 背景。

## Validation

需要满足以下结果：

1. 折叠态右侧扩展块与刘海右下角之间不再露出背景缝隙。
2. 图标位置与扩展块整体宽度感知基本保持不变。
3. 展开态和 hover 行为不回归。
